# Results and Evaluation

This folder is reserved for outputs generated by running the MATLAB workflow on actual crop images.

## What to save for each test image

Run `weed detection in crops/Code/main_reviewed.m` in MATLAB and select a source image. The script creates a sibling output folder containing:

| Output | What it contains |
|---|---|
| `01_original.png` | Original input image |
| `02_excess_green.png` | Normalized Excess Green index |
| `03_filtered.png` | Median-filtered vegetation index |
| `04_initial_mask.png` | Otsu-threshold binary mask |
| `05_cleaned_mask.png` | Morphologically cleaned mask |
| `06_detection_overlay.png` | Candidate-region overlay |
| `07_processing_stages.png` | Processing-stage comparison |
| `candidate_regions.csv` | Region area, eccentricity and centroid measurements |

The output directory is created beside the selected image. Copy the generated files here only when you want to publish those specific results.

## Evaluation protocol

Candidate-region counts and image-processing outputs are descriptive results, not accuracy metrics.

To calculate precision, recall, F1-score, specificity or IoU:

1. Prepare a representative set of test images.
2. Manually annotate the ground-truth weed regions (and crop regions if crop-versus-weed discrimination is being evaluated).
3. Define the evaluation unit and matching rule before comparing predictions with annotations.
4. Compare the MATLAB output against the annotations using the same image dimensions and masks.
5. Report the number of images, annotation procedure, thresholds, parameter settings and aggregate metrics.

The current ExG workflow highlights green-vegetation candidates. It does not independently establish whether each candidate is a weed or a crop plant.

## Research-paper metrics

Metrics quoted from external research papers must be labelled as published-paper results and kept separate from measurements produced by this repository. Do not present them as performance results of this MATLAB implementation.
